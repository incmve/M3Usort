Normally the backup must have been made with the same M3USORT_KEY as in your .env now. With the box ticked, everything else comes back (settings, library, wanted list, admin password) and you enter the provider, Jellyfin, TMDB and SMB passwords again under Admin → Settings. It is checked first; if it's fine, M3Usort restarts and replaces its database with the backup. The current database is kept as m3usort.db.before-restore-… in the data folder.
