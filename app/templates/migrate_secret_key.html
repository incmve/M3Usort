Security Action Required
SECRET_KEY found in config.py

Your SECRET_KEY is stored inside config.py, which is included in backups and should never contain secrets. It must be moved to your .env file so it stays outside of the backup.

Step 1 — Copy this line into your .env file next to your docker-compose.yml:

SECRET_KEY={{ secret_key_in_config }}

Step 2 — Restart your container so Docker picks up the new .env value:

docker compose down && docker compose up -d

Step 3 — Once the key is in your .env and the container is restarted, click the button below. This will remove SECRET_KEY from config.py.
